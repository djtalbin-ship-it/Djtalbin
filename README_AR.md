# AnyPS5 Progress Pro — إصدار أندرويد 2.0

## المميزات
- واجهة عربية داكنة مصممة للهاتف.
- لوحة رئيسية لنسب تقدم مكتبات النظام وتعليمات GPU.
- تحميل البيانات الحية من `https://boykopovar.github.io/AnyPS5/progress.json`.
- قائمة قابلة للبحث بالمكتبات/مجموعات تعليمات GPU.
- تفاصيل لعناصر المكتبة، بما في ذلك أمثلة للعناصر المتبقية.
- صفحة لفتح لوحة التقدم الرسمية.

## حدود الإصدار
- يحتاج الإنترنت لتحديث البيانات.
- يعرض بيانات التقدم المنشورة؛ لا يشغّل ألعاب PS5 ولا ينفذ محاكاة.
- هذا مشروع مصدر، وليس APK جاهزًا. يجب بناؤه في Android Studio.

## بناء APK
1. افتح المجلد في Android Studio.
2. انتظر Gradle Sync وتنزيل SDK 35 عند الطلب.
3. اختر Build > Build APK(s).
4. ثبّت APK الناتج على الهاتف.

## حزم المشروع
Android Studio / Kotlin، دون مكتبات واجهة خارجية.


## بناء تلقائي عبر GitHub Actions
أُضيف ملف سير عمل في `.github/workflows/build-apk.yml`. يحتاج المشروع إلى ملفات Gradle Wrapper (`gradlew` ومجلد `gradle/wrapper`) قبل أن ينجح البناء التلقائي. إذا لم تكن هذه الملفات موجودة في المشروع، افتح المشروع مرة واحدة في Android Studio أو أنشئ Gradle Wrapper على جهاز فيه Gradle، ثم ارفع الملفات إلى GitHub.
